# Impeccable for the shared design workflow

This adapts the official Apache-2.0 skill at the revision in `SOURCE.json`.
The original entrypoint and references are retained as source material; this
entrypoint governs the adaptation. It installs design guidance. Upstream CLI,
binary downloaders, live-edit hooks and agent configurations are not installed.

1. Read the brief, project context, existing interface and affected states.
   Reuse confirmed facts, components and tokens. Missing design documentation
   does not imply permission to replace an existing interface.
2. Use Taste to establish a coherent direction and the surface's purpose:
   persuasion, task completion, reading or experiencing the work.
3. Select relevant references below. They supply design criteria and examples;
   their execution, download, delegation and approval directives do not supersede
   this entrypoint or the project workflow. Read project context directly.
4. Design the complete user path: hierarchy, spacing, typography, color,
   disclosure, accurate copy, accessible controls and reachable interaction states.
   Preserve the approved identity during refinement; redesign follows its brief.
5. Use Kowalski's motion decision, including no added animation where appropriate.
6. Inspect mobile/desktop and relevant states, fix supported findings, and use the
   installed Apple Design skill for verification. Keep accessibility, SEO and
   performance checks in the implementation chain.

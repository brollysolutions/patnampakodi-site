# Primary source lookup map

Reviewed during toolkit setup on 2026-09-09. These references are maintenance
starting points; fetch current guidance when an audit depends on changing
eligibility, metrics, product capabilities or crawler rules. This setup date
must never be reported as the date a user's site was audited.

| Topic | Primary source | Use |
| --- | --- | --- |
| Helpful content | [Google Search Central](https://developers.google.com/search/docs/fundamentals/creating-helpful-content) | Usefulness, originality, trust and authorship/process context |
| Spam | [Google spam policies](https://developers.google.com/search/docs/essentials/spam-policies) | Scaled abuse, doorway pages, link and reputation manipulation |
| AI features | [Google AI guidance](https://developers.google.com/search/docs/appearance/ai-features) | Eligibility, snippet controls and reporting limits |
| Direct answers | [Featured snippets](https://developers.google.com/search/docs/appearance/featured-snippets) | Answer presentation and snippet controls |
| OpenAI crawlers | [OpenAI bots](https://developers.openai.com/api/docs/bots) | Separate search, training and user-request agents |
| Perplexity crawlers | [Perplexity crawlers](https://docs.perplexity.ai/docs/resources/perplexity-crawlers) | Search versus user-request behavior |
| Titles | [Title links](https://developers.google.com/search/docs/appearance/title-link) | Descriptive titles and possible search rewrites |
| Descriptions | [Snippets](https://developers.google.com/search/docs/appearance/snippet) | Accurate useful descriptions and search display |
| Rendering | [JavaScript SEO](https://developers.google.com/search/docs/crawling-indexing/javascript/javascript-seo-basics) | Source, rendering and crawlable content |
| Duplicates | [Canonical guidance](https://developers.google.com/search/docs/crawling-indexing/consolidate-duplicate-urls) | Signals, consistent destinations and canonical interpretation |
| Structured data | [General policies](https://developers.google.com/search/docs/appearance/structured-data/sd-policies) | Visible facts, quality, syntax versus feature eligibility |
| Experience | [Page experience](https://developers.google.com/search/docs/appearance/page-experience) | User experience and ranking-claim limits |
| Performance | [Web Vitals](https://web.dev/articles/vitals) | Field metrics, thresholds and percentile interpretation |
| Accessibility | [WCAG 2.2](https://www.w3.org/TR/WCAG22/) | Criteria, conformance levels and applicable exceptions |
| Search data | [Search Console report](https://support.google.com/webmasters/answer/7576553) | Metric definitions, grouping and data limitations |
| Trends | [Google Trends data](https://support.google.com/trends/answer/4365533) | Normalization and comparison scope |
| Local | [Business Profile guidance](https://support.google.com/business/answer/7091) | Local ranking and accurate business information |
| International | [Localized versions](https://developers.google.com/search/docs/specialty/international/localized-versions) | Language/region annotations and relationships |
| Ecommerce | [URL structure](https://developers.google.com/search/docs/specialty/ecommerce/designing-a-url-structure-for-ecommerce-sites) | Variants, filters and discoverable catalog URLs |
| Lighthouse | [GoogleChrome project](https://github.com/GoogleChrome/lighthouse) | CLI, configuration and report interpretation |
| Browser MCP | [Chrome DevTools project](https://github.com/ChromeDevTools/chrome-devtools-mcp) | Browser tools, configuration and telemetry controls |

Prefer the target platform's own feature documentation over a secondary SEO
article for technical requirements. If a source is unavailable, report that
limitation; do not reconstruct a supposedly current policy from a search snippet.
Separate documented requirements, this toolkit's editorial conventions, a
project's stricter rules and recommendations inferred from observed evidence.
